# Mean-Variance-Standard-Deviation-Calculator


This project is a simple Python-based calculator that computes key statistical measures — **Mean**, **Variance**, **Standard Deviation**, **Minimum**, **Maximum**, and **Sum** — from a 3x3 matrix of numbers using **NumPy**.

## Features
- Accepts 9 space-separated integers as input.
- Reshapes the input into a 3x3 NumPy array.
- Calculates:
  - Mean
  - Variance
  - Standard Deviation
  - Min and Max values
  - Sum
- Computes all statistics:
  - Along columns
  - Along rows
  - For the entire matrix

## How to Use
1. Run the script.
2. Enter 9 integers separated by spaces when prompted.
3. View the dictionary output containing all statistical measures.
